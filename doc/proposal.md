# 基于深度学习的 A 股短期趋势预测与模拟交易需求文档

## 1. 项目背景

本项目面向“基于深度学习的股票趋势预测与模拟交易”课程大作业。项目目标是使用 Python 构建一套可复现的量化研究流程：读取 A 股历史数据，构造不含未来信息泄露的训练样本，训练至少一个神经网络模型，评估模型预测能力，并将模型信号转化为可用于模拟盘的交易建议。

本项目的设计原则不是单纯追求历史收益最大化，而是在课程完成度、实现可解释性、模拟盘可运行性之间取得平衡。项目最终需要支持比赛期间每日盘后更新数据后生成下一交易日的候选买卖清单。

## 3. 股票基础概念说明

由于项目开发者不具备股票背景，需求文档中先固定以下概念口径：

- A 股：在中国大陆证券交易所上市、以人民币交易的股票。
- ST 股票：被交易所进行特别处理的股票，通常风险较高；比赛要求排除。
- 北交所股票：北京证券交易所上市股票；比赛要求排除。
- 收益率：股票价格变化比例，例如 `(卖出价 - 买入价) / 买入价`。
- 短期趋势预测：预测股票在未来 1 至 5 个交易日内相对上涨或下跌的可能性。
- IC：同一天内，模型给不同股票的预测分数与这些股票未来真实收益之间的相关系数。
- ICIR：IC 均值除以 IC 波动，用于衡量预测能力是否稳定。
- 最大回撤：历史净值从高点跌到低点的最大跌幅。
- 夏普比率：单位风险下获得的收益，越高通常表示收益风险比越好。

## 4. 预测目标选择依据

本项目需要确定“模型到底预测什么”。用户尚未指定预测周期，因此参考权威量化研究和开源量化框架的常见做法后，确定如下方案：

1. 主预测目标：用交易日 `T` 及以前的数据，在 `T` 日盘后生成信号，预测股票在 `T+1` 买入后到 `T+2` 的收益率。
2. 辅助预测目标：同时保留未来 3 日、未来 5 日收益率作为实验对照，用于分析更长持有期是否更稳定。
3. 模型输出形式：输出连续预测分数，而不是只输出涨跌分类。连续分数既可计算 IC / ICIR，也可用于股票排序和组合权重分配。

选择理由：

- 课程任务强调“短期收益方向”和模拟交易，日频调仓最直接对应 1 至 5 个交易日预测。
- Microsoft Qlib 等量化研究框架常用未来可交易区间收益作为标签，并使用 IC、回测收益等指标评估模型。
- WorldQuant 101 Formulaic Alphas 等短线 alpha 研究关注的是数日级别的股票排序信号。
- A 股存在 T+1 交易约束，当日买入不能当日卖出，因此主标签采用 `T+1` 买入、`T+2` 卖出的收益，更贴近模拟盘执行。

参考来源：

- Microsoft Qlib: https://github.com/microsoft/qlib
- Gu, Kelly, Xiu, “Empirical Asset Pricing via Machine Learning”: https://academic.oup.com/rfs/article/33/5/2223/5758276
- Kakushadze, “101 Formulaic Alphas”: https://arxiv.org/abs/1601.00991

## 5. 数据需求

### 5.1 输入数据

项目读取 `A股数据/` 下的数据：

| 数据目录 / 文件 | 用途 |
| --- | --- |
| `basic.csv` | 获取股票基本信息，过滤北交所股票 |
| `trade_cal.csv` | 获取交易日历，处理 T、T+1、T+2 等交易日关系 |
| `daily/` | 构造基础量价特征和收益率标签 |
| `metric/` | 构造基本面和估值类特征 |
| `moneyflow/` | 构造资金流向特征 |
| `news/` | 构造新闻文本情绪或文本嵌入特征 |
| `stock_st/` | 每日过滤 ST 股票 |
| `market/` | 获取上证指数、沪深 300、创业板指数作为回测基准 |
| `index_weight/` | 用于构造沪深 300 等小股票池验证阶段 |

### 5.2 数据时间范围

- 训练与验证数据起点：2019-01-01。
- 原因：新闻数据从 2019 年开始，使用 2019 年之后的数据可以保证特征体系一致。
- 回测验证区间：2026-01-01 至 2026-05-20。
- 训练区间：2019-01-01 至 2025-12-31。

### 5.3 股票池阶段

项目分两个阶段实施：

1. 小股票池验证阶段：优先使用沪深 300 或高流动性股票池，验证数据读取、特征工程、模型训练、回测流程是否完整。
2. 官方股票池阶段：扩展到除 ST 和北交所外的全部 A 股，生成可用于模拟盘的每日预测结果。

## 6. 数据处理需求

### 6.1 数据清洗

系统需要完成：

- 合并每日截面 CSV 为可训练的日期-股票二维数据。
- 按 `ts_code` 和 `trade_date` 对齐 `daily`、`metric`、`moneyflow`。
- 将新闻按自然日或交易日聚合到对应交易日。
- 过滤上市时间过短、缺失数据过多、停牌或成交额异常低的股票。
- 每日过滤 ST 股票。
- 过滤 `basic.csv` 中 `market = 北交所` 的股票。

### 6.2 特征工程

基础量价特征：

- 日收益率、开盘到收盘收益率、最高最低振幅。
- 成交量变化率、成交额变化率、VWAP 偏离度。
- 过去 5 / 10 / 20 日移动平均、波动率、动量。

基本面特征：

- 换手率、量比、市盈率、市净率、市销率、市值等。
- 对极端值进行截尾或分位数裁剪。

资金流特征：

- 小单、中单、大单、特大单买卖差额。
- 净流入额、净流入额占成交额比例。
- 过去多日资金流滚动均值。

新闻特征：

- 每日新闻数量。
- 新闻标题和正文的文本表示。
- 初始版本可以使用 TF-IDF 或轻量中文文本向量；后续可尝试中文预训练模型生成 embedding。
- 新闻特征只允许使用信号生成日之前已经发布的新闻。

### 6.3 防止未来信息泄露

必须满足以下约束：

- 对交易日 `T+1` 的预测，只能使用 `T` 日盘后或更早已经可获得的数据。
- 标签中的未来收益不得参与任何特征计算。
- 标准化、缺失值填充、截尾阈值、行业中性化等统计量只能在训练期或历史滚动窗口中拟合。
- 验证期和回测期不得重新使用未来全样本统计量。
- 股票池过滤需要按日执行，不能用未来日期的 ST 状态过滤历史样本。

## 7. 标签定义

主标签定义为：

```text
label_1d(T) = close(T+2) / close(T+1) - 1
```

含义：

- 在 `T` 日盘后得到全部可用数据。
- 模型在 `T` 日盘后生成预测分数。
- 策略在 `T+1` 交易日买入。
- 因 A 股 T+1 约束，最早在 `T+2` 交易日卖出。

辅助标签：

```text
label_3d(T) = close(T+4) / close(T+1) - 1
label_5d(T) = close(T+6) / close(T+1) - 1
```

辅助标签用于实验比较，不作为第一版模型必须优化目标。

## 8. 模型需求

### 8.1 基线模型

必须实现至少一个简单基线，用于证明深度学习模型是否有效：

- 线性回归或 LightGBM 作为非深度学习基线。
- 简单 MLP 作为深度学习基线。

### 8.2 深度学习模型

第一阶段模型：

- MLP：输入截面特征，输出未来收益预测分数。
- GRU / LSTM：输入过去若干交易日的特征序列，输出预测分数。

第二阶段模型：

- Transformer Encoder：输入过去 `lookback` 日的多维特征序列，学习时间依赖关系。
- 可选加入股票行业、市值分组、市场状态等辅助特征。

### 8.3 模型训练要求

- 按时间划分训练集和验证集，不允许随机打乱时间。
- 训练期：2019-01-01 至 2025-12-31。
- 验证 / 回测期：2026-01-01 至 2026-05-20。
- 损失函数优先使用 MSE 或 RankIC 相关损失。
- 保存训练日志、训练损失曲线、验证损失曲线。
- 保存模型配置，不提交大体积模型权重。

## 9. 交易策略需求

本项目不采用老师示例中的固定 `n` 只持仓、每天换出 `k` 只的简单策略，而采用更接近模拟盘的复杂策略框架。

### 9.1 策略输入

每日策略输入包括：

- 当前交易日可交易股票池。
- 每只股票的模型预测分数。
- 当前持仓。
- 当前可用现金。
- 当日涨跌停、停牌、成交额等可交易状态。

### 9.2 策略逻辑

策略应支持：

- 按预测分数筛选候选股票。
- 排除 ST、北交所、停牌、无法买入或无法卖出的股票。
- 根据预测分数、市值、流动性、行业分散度生成目标持仓。
- 根据 T+1 规则判断哪些持仓当日允许卖出。
- 根据手续费、滑点、最小交易单位计算可执行订单。
- 尽量满仓，符合模拟交易比赛要求。

### 9.3 候选复杂策略

系统需要至少实现一种复杂策略，并保留对比方案：

| 策略 | 说明 | 用途 |
| --- | --- | --- |
| TopK 等权组合 | 选择预测分数最高的若干股票等权持有 | 简单对照 |
| 分数加权组合 | 权重与预测分数强度相关 | 主策略候选 |
| 风险约束组合 | 限制单票权重、行业集中度、换手率 | 主策略候选 |
| 止损 / 止盈规则 | 对异常下跌或达到收益目标的持仓进行处理 | 模拟盘增强 |

最终模拟盘策略不在需求阶段固定单一参数，而是在验证回测区间通过收益、夏普、最大回撤、换手率和可执行性综合选择。

## 10. 回测需求

### 10.1 回测约束

回测必须尽量模拟真实交易：

- 初始资金：100 万元。
- 满仓约束：每日尽量使用全部现金持股。
- T+1 约束：当日买入股票不能当日卖出。
- 手续费：需要配置参数，默认按 A 股常见交易成本估算。
- 滑点：需要配置参数，用于模拟成交价格偏离。
- 涨跌停：涨停股票不能买入，跌停股票不能卖出。
- 停牌：停牌股票不能交易。
- 最小交易单位：A 股买入通常按 100 股整数倍。

### 10.2 评估指标

模型预测指标：

- 训练损失曲线。
- 验证损失曲线。
- 日度 IC。
- IC 均值。
- ICIR。
- 方向准确率。

回测指标：

- 累计收益率。
- 年化收益率。
- 夏普比率。
- 最大回撤。
- 换手率。
- 持仓股票数量。
- 每日交易记录。

基准对比：

- 沪深 300 指数。
- 上证指数。
- 简单 MLP 模型。
- TopK 等权简单策略。

## 14. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 股票数据量大，训练慢 | 无法快速迭代 | 先用小股票池跑通流程，再扩展全部股票 |
| 新闻文本处理复杂 | 实现成本高 | 第一版使用简单文本统计或 TF-IDF，后续再尝试深度文本模型 |
| 历史回测收益差 | 结果不理想 | 强调规范流程、无泄露、对比分析和反思 |
| 数据泄露 | 回测结果虚高且不可用于模拟盘 | 所有统计量按训练期或滚动历史拟合 |
| 模拟盘无法成交 | 实盘结果偏离模型 | 回测中加入涨跌停、停牌、滑点、最小交易单位约束 |
| 过拟合 | 验证期表现不稳定 | 使用时间切分、早停、正则化和基准模型对照 |
