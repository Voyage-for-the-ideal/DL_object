# features 模块任务

## 模块目标

基于数据模块输出构造量价、基本面、资金流、新闻和预处理特征，并保证所有特征只使用信号日 `T` 及以前可获得的数据。

## 最小任务清单

- [x] FE001 实现特征表统一格式检查，要求所有模块输出 `trade_date, ts_code, feature_*`。
- [x] FE002 实现 `price_features` 的基础量价特征：日收益率、开盘到收盘收益率、最高最低振幅、VWAP 偏离度。
- [x] FE003 实现成交量和成交额变化率特征，并处理除零和缺失值。
- [x] FE004 实现 5、10、20 日滚动均值、波动率、动量、成交量均值、成交额均值，窗口右端必须不超过 `T`。
- [x] FE005 为量价特征写泄露测试：修改 `T+1` 之后价格，不应改变 `T` 日特征。
- [x] FE006 实现 `metric_features`，包含换手率、量比、PE、PE_TTM、PB、PS、PS_TTM、股息率、总市值、流通市值和市值对数。
- [x] FE007 实现基本面极端值标记或预清洗逻辑，具体裁剪阈值留给 `preprocess` 拟合。
- [x] FE008 实现 `moneyflow_features`，包含各类资金买卖差额、净流入额、净流入占成交额比例。
- [x] FE009 实现资金流 5、10、20 日滚动均值和资金流强度截面排名。
- [x] FE010 实现 `news_features` 第一版市场级新闻统计：新闻数量、标题数量、正文长度均值、聚合文本。
- [x] FE011 实现新闻 TF-IDF 特征生成器，`fit` 只接收训练期文本，验证、回测和每日预测只调用 `transform`。
- [x] FE012 实现无新闻日期处理，输出全零 TF-IDF 向量和新闻数量 0。
- [x] FE013 实现特征合并函数，按 `(trade_date, ts_code)` 合并 daily、metric、moneyflow 和市场级新闻特征。
- [x] FE014 实现 `preprocess` 的训练期分位数截尾、训练期中位数填充、训练期均值方差标准化。
- [x] FE015 实现 `daily_rank` 预处理模式，只使用当日截面数据生成排名特征。
- [x] FE016 实现预处理器保存和加载，保证同一输入在保存前后输出一致。
- [x] FE017 实现 `feature_store` 缓存，缓存路径包含配置哈希或配置摘要，配置变化时不误用旧缓存。
- [x] FE018 实现最小特征流水线 smoke test：少量股票、少量交易日可以生成合并特征表。

## 完成标准

- [x] 每个特征模块都能独立运行并输出统一主键。
- [x] 训练期拟合的预处理参数不会被验证期或回测期数据改变。
- [x] 新闻 TF-IDF 词表不从验证期重新拟合。
- [x] 特征缓存可删除重建，且不会影响结果语义。
