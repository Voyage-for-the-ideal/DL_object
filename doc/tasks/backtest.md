# backtest 模块任务

## 模块目标

把每日预测分数转化为可执行交易，模拟 T+1、手续费、滑点、涨跌停、停牌、最小交易单位和满仓约束，并输出净值、交易记录、持仓记录和回测指标。

## 最小任务清单

- [x] B001 定义 `PortfolioState` 和 `Position` 数据结构，包含现金、持仓、成本价、最新价、买入日期和总资产。
- [x] B002 明确回测时间语义：`signal_date = T`，`trade_date = T+1`，回测循环按 `trade_date` 推进。
- [x] B003 实现行情和信号读取，交易日使用上一交易日信号。
- [x] B004 实现 `execution` 的停牌判断，当日无行情、成交量为 0 或成交额异常低时不可交易。
- [x] B005 实现涨停不能买、跌停不能卖约束。
- [x] B006 实现 T+1 约束，当日买入股票当日不可卖出。
- [x] B007 实现手续费、滑点、印花税配置项和成交金额计算。
- [x] B008 实现最小交易单位，买入股数向下取整到 100 股整数倍。
- [x] B009 实现 TopK 等权对照策略，按 score 降序选择前 `top_k`。
- [x] B010 实现分数加权策略，支持正分数归一化、rank 归一化或 softmax 中至少一种。
- [x] B011 实现风险约束：单票权重上限、行业权重上限、流动性过滤、换手率约束中的第一版可用子集。
- [x] B012 实现不可买入高分股票的候选替补逻辑，或明确保留现金原因。
- [x] B013 实现回测主循环：生成目标持仓、生成订单、执行订单、更新持仓、更新净值。
- [x] B014 输出 `nav.csv`、`trades.csv`、`positions.csv`、`orders.csv`、`backtest_metrics.json`、`nav_curve.png`。
- [x] B015 实现回测指标：累计收益率、年化收益率、年化波动率、夏普比率、最大回撤、换手率、平均持仓数量、现金比例、成交失败比例。
- [x] B016 实现基准净值读取和对比，至少支持沪深 300 和上证指数。
- [x] B017 为执行模块写单元测试：T+1、最小单位、涨停买入拒绝、跌停卖出拒绝。
- [x] B018 为指标模块写单元测试：单调上涨净值最大回撤为 0，已知收益序列累计收益正确。
- [x] B019 实现 3 至 5 个交易日的小回测 smoke test，验证现金、股数和净值不出现异常负值。

## 完成标准

- [x] 回测可以覆盖 2026-01-01 至 2026-05-20 区间。
- [x] 回测交易约束与需求文档一致。
- [x] 主策略和 TopK 对照策略都能输出可比较结果。
- [x] 回测模块使用预测分数和行情状态，不直接重新训练模型。
